# Campus Voice
## Serverless Student Feedback Management System

### Project Overview
Campus Voice is a serverless web application that allows students to submit feedback about their courses and faculty members. Administrators can view submitted feedback through an admin dashboard.

### Technologies Used
- HTML, CSS and JavaScript
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Python

### Main Features
- Student feedback submission
- Course and faculty feedback
- Feedback ratings and comments
- Admin dashboard to view feedback
- Serverless backend using AWS services

### How It Works
1. Students submit feedback through the website.
2. API Gateway receives the request and invokes AWS Lambda.
3. Lambda processes the request and stores feedback in DynamoDB.
4. Administrators retrieve and view submitted feedback through the dashboard.
